================================================================================
                            QUICK START
================================================================================

1. CLONE & INSTALL
   git clone <repo>
   cd seva-os
   npm install
   cp .env.example .env

2. GET API KEYS
   - Supabase: https://supabase.com
   - Gemini: https://aistudio.google.com/app/apikey
   - WhatsApp: https://developers.facebook.com

3. FILL .env
   SUPABASE_URL=...
   SUPABASE_SERVICE_ROLE_KEY=...
   WA_PHONE_NUMBER_ID=...
   WA_ACCESS_TOKEN=...
   WA_VERIFY_TOKEN=...
   GEMINI_API_KEY=...

4. RUN LOCALLY
   npm start
   # Server running on http://localhost:3000

5. TEST
   node test-webhook.js verify
   node test-webhook.js coordinator "Food needed at 400001"
   node test-webhook.js volunteer "YES"

6. DEPLOY
   git push origin main
   # Follow DEPLOYMENT.md for Render setup

                            KEY FEATURES
================================================================================

✅ COORDINATOR INTERFACE
   - Send needs via WhatsApp
   - LLM extracts: category, location, urgency
   - Automatic volunteer matching

✅ VOLUNTEER DISPATCH
   - Sends alerts to top 3 available volunteers
   - Tracks responses: YES/NO/DONE/STUCK
   - Updates volunteer status automatically

✅ STATE MACHINE
   - Pending → Accepted → Done (or Stuck)
   - Automatic status transitions
   - Reliability scoring

✅ IMPACT TRACKING
   - Increments volunteer impact on DONE
   - Decrements reliability on STUCK
   - Leaderboards & analytics

✅ ADMIN TOOLS
   - Register volunteers

   - Reset statuses
